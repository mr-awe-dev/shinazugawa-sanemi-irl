## **🌪️ DAILY TASKS**

**(`*Pernapasan Konsentrasi Penuh: Rutinitas Harian*`)**

- [ ]  **Nutrisi "Ransum Hashira" (Protein Tinggi & Defisit Ringan):**
    - [ ]  Target Protein: Konsumsi sekitar `140g - 160g protein setiap hari` (`dada ayam, telur, tempe, ikan, whey protein`). Ini penting untuk menjaga otot Anda agar tidak menyusut saat lemak dibakar.
    - [ ]  Defisit Kalori Ringan: `Makanlah sekitar 300-500 kalori di bawah kebutuhan harian` (TDEE) Anda. Fokus pada makanan utuh (*whole foods*) dan hindari gula serta makanan olahan. Sanemi tidak peduli pada makanan manis; ia makan untuk fungsi dan tenaga.
- [ ]  **Hidrasi Total Concentration:**
    - [ ]  `Minum minimal **3 - 4 liter air putih** sehari`. Otot yang terhidrasi pulih lebih cepat dan terlihat lebih padat (penuh).
- [ ]  **Postur & Aktivitas NEAT:**
    - [ ]  `Sanemi selalu berdiri tegap dengan dada membusung dan bahu ditarik ke belakang`. Sadari postur Anda sepanjang hari.
    - [ ]  Perbanyak `jalan kaki (target 8.000 - 10.000 langkah sehari).` Ini adalah cara paling efektif membakar lemak tanpa membuat Anda kelelahan untuk sesi latihan utama.
- [ ]  **Tidur Pemulihan (7-8 Jam):**
    - [ ]  Otot tidak tumbuh di gym; mereka tumbuh saat Anda tidur. `Tidur yang cukup mengatur hormon testosteron dan kortisol (hormon stres)` Anda.

## **⚔️** Weekly Tasks

(**`*Latihan Pilar Angin & Evaluasi*`**)

Fokus latihan mingguan Anda harus meniru gerakan menebas pedang Nichirin: **kekuatan tarikan (pull), kekuatan genggaman (grip), otot inti yang eksplosif (core), dan kelincahan kaki.**

**Jadwal Latihan (4-5 Hari Seminggu):**

**Hari 1: Upper Body Pull & Grip (Punggung, Biceps, Forearm)**

*Fokus: Punggung lebar (V-taper), biceps, dan lengan bawah.*

- [ ]  **`Pull-ups / Chin-ups`**: 4 set x maksimal repetisi (jika belum kuat, gunakan kursi untuk bantu naik, lalu turun perlahan 3-5 detik).
- [ ]  **`Gallon 15L Bent-Over Row`**: 4 set x 10-15 repetisi per tangan (pegang gagang galon, condongkan badan, tarik galon ke arah pinggang).
- [ ]  **`Dumbbell Bicep Curls`**: 3 set x 12-15 repetisi.
- [ ]  **`Gallon Farmer’s Carry`**: 3 set x 30-60 detik berjalan mondar-mandir di rumah sambil menjinjing galon 15L dengan satu atau dua tangan. (Pastikan tutup galon kencang!).
- [ ]  *Sanemi Special:* **Farmer's Walks** dan **Dead Hangs** (`bergantung di tiang pull-up selama mungkin`). Ini akan membangun lengan bawah yang berurat dan cengkeraman yang kuat untuk memegang pedang.

**Hari 2: Lower Body & Plyometrics (Kaki & Kelincahan)**

*Fokus: Kaki yang kuat, stabil, dan eksplosif.*

- [ ]  **`Gallon Goblet Squats`**: 4 set x 12-15 repetisi (peluk galon 15L di depan dada, squat dalam).
- [ ]  **`Bulgarian Split Squats`**: 3 set x 8-12 repetisi per kaki (kaki belakang di atas kursi/sofa, pegang 2 dumbbell atau galon di tangan).
- [ ]  **`Jump Squats (Bodyweight)`**: 3 set x 10-15 repetisi (ledakkan tubuh ke atas, mendarat dengan lembut).
- [ ]  **`Single-Leg Calf Raises`**: 3 set x 15-20 repetisi per kaki (berdiri di tepi anak tangga atau tumpukan buku).

**Hari 3: Active Recovery / Mobility**

- [ ]  `Jalan santai, stretching, atau yoga`. Jaga kelenturan bahu dan pinggul agar tidak mudah cedera.

**Hari 4: Upper Body Push (Dada, Bahu, Triceps)**

*Fokus: Dada, bahu bundar, dan triceps.*

- [ ]  **`Push-up Variations`**: 4 set x maksimal repetisi (ganti-ganti: standard, diamond untuk triceps, dan decline/kaki di atas kursi untuk dada atas).
- [ ]  **`Dumbbell/Gallon Overhead Press`**: 4 set x 10-12 repetisi (duduk atau berdiri, dorong beban ke atas kepala).
- [ ]  **`Dumbbell Lateral Raises`**: 4 set x 15-20 repetisi (angkat dumbbell ke samping untuk bahu yang lebar. Jika dumbbell terlalu berat, gunakan botol air 1.5L).
- [ ]  **`Floor Tricep Extensions (Skullcrushers)`**: 3 set x 12-15 repetisi menggunakan 1 atau 2 dumbbell.

**Hari 5: "Wind Breathing" Core & HIIT (Otot Perut & Stamina)**

*Fokus: Otot perut tajam dan stamina kardiovaskular.*

- [ ]  **`Hanging Leg/Knee Raises`** (di pull-up bar): 3 set x 8-12 repetisi (angkat lutut atau kaki lurus ke arah dada).
- [ ]  **`Gallon Russian Twists`**: 3 set x 20 repetisi total (duduk di lantai, angkat kaki sedikit, putar galon 15L dari kiri ke kanan).
- [ ]  **`Mountain Climbers`**: 3 set x 40 detik.
- [ ]  **`HIIT Sederhana`**: 10-15 menit (contoh: 30 detik Burpees / Lompat Tali / Sprint di tempat, diikuti 30 detik istirahat, ulangi 10-15 kali).

**Hari 6 & 7:** **`Istirahat total atau aktivitas ringan.`**

### **💨 Evaluasi Mingguan (Setiap Hari Minggu Pagi):**

- Timbang berat badan setelah buang air kecil dan sebelum makan/minum.
- **Ukur lingkar pinggang** menggunakan meteran jahit. `Jika berat badan tetap (misal 73 kg) tapi lingkar pinggang mengecil, itu artinya Anda sukses membakar lemak dan mengganti/membangun otot (*body recomposition*).`

## **🗓️** Monthly Tasks

 **(*Evaluasi Hashira & Adaptasi*)**

Setiap bulan, Anda harus melihat hasil kerja keras Anda secara objektif dan menyesuaikan strategi.

- [ ]  **Progress Pictures (Foto Kemajuan):**
    
    Setiap 4 minggu, ambil foto tubuh Anda dari 3 sisi (depan, samping, belakang) di tempat yang sama dengan pencahayaan yang sama. Cermin dan foto tidak bisa berbohong; ini lebih akurat daripada timbangan.
    
- [ ]  **Progressive Overload (Beban Progresif):**
    
    Evaluasi catatan latihan Anda. Apakah bulan ini Anda bisa melakukan Pull-up lebih banyak? Apakah beban Squat Anda bertambah? Jika ya, otot Anda sedang tumbuh. Jika tidak, Anda harus memaksa diri untuk menambah beban atau repetisi di bulan berikutnya.
    
- [ ]  **Penyesuaian Kalori (Diet Adjustment):**
    
    Jika setelah 4 minggu lemak tubuh belum berkurang, turunkan asupan kalori harian Anda sebanyak 100-200 kkal (biasanya dari karbohidrat).
    
    Jika Anda merasa sangat lemas dan tenaga saat latihan menurun drastis, tambah sedikit karbohidrat di sekitar waktu latihan (sebelum dan sesudah gym).
    
- [ ]  **Deload Week (Minggu Pemulihan):**
    
    Setiap bulan ke-2 atau ke-3, ambil satu minggu di mana Anda mengurangi beban latihan hingga 50%. Ini memberi waktu bagi sistem saraf pusat dan sendi Anda untuk beristirahat dari "pertempuran" berat, mencegah cedera, dan memecah fase *plateau* (stuck).
